# Bank Management System – Java

## Project Overview
The Bank Management System is a console-based Java application developed using Core Java and Object-Oriented Programming (OOP) concepts.

The application allows users to create bank accounts, deposit money, withdraw money, view account balances, and display all existing accounts.

## Features
- Create a new bank account.
- Deposit money into an account.
- Withdraw money from an account.
- Check account balance.
- Display all existing bank accounts.
- Manage multiple customer accounts.

## Class Description

### 1. BankAccount.java
- Represents an individual bank account.
- Stores account information.
- Handles deposit operations.
- Handles withdrawal operations.
- Maintains account balance.

### 2. BankManagementSystem.java
- Contains the main method.
- Provides a menu-driven interface.
- Creates and manages bank accounts.
- Allows users to perform banking operations.
- Displays account details and balances.

## How to Run
1. Install JDK on your system.
2. Open the project in IntelliJ IDEA or VS Code.
3. Open `BankManagementSystem.java`.
4. Run the main method.
5. Select the required banking operation from the console menu.
